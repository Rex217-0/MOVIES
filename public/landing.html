Ano ang kaya nito

🎬

Feature Film Factory

18 eksena, tuloy-tuloy na batch, awtomatikong stitch patungong isang MP4. Hindi tumitigil ang batch kapag may isang eksenang bumagsak.

🧠

Direk (script + bible)

Filipino/Taglish na screenwriter. May guard: hindi gumagawa ng quote o diyalogo para sa totoong tao.

🎥

Free-first video

ComfyUI (lokal GPU) → libreng motion engine (image + ffmpeg) → Wan 2.2 kung naka-opt-in ang ALLOW_PAID_CLOUD.

🔊

Tagalog TTS

Bundled offline na boses, o Piper/Fish kapag naka-configure. Narration sa bawat eksena.

🕸️

GPU mesh

Idagdag ang ibang PC (o phone) bilang worker sa scripts/worker.mjs para maghati sa render load.

📱

Android remote

Thin WebView app na kumokonekta sa server. Ang mabibigat na gawain ay nasa server pa rin.

Paano magsimula

  1. Patakbuhin ang server (npm run dev o npm start) sa Server-2.
  2. I-set ang .env: COMFYUI_URL, COMFYUI_VIDEO_WORKFLOW, at APP_AUTH_TOKEN.
  3. Buksan ang Dashboard para makita kung alin ang naka-kabit at handa.
  4. I-install ang Android APK sa phone at ilagay ang server address.
